## 1. Case Study: StitchSmart AI E-Commerce Platform
- **FYP Title**: AI-Powered Hybrid B2B & B2C eCommerce SaaS with RAG Vector Search
- **Primary Keywords**: `AI FYP Project Pakistan`, `RAG Based Final Year Project`, `Gemini API Project`, `AI Ecommerce FYP`
- **Problem Statement**: Retail and wholesale shoppers require dual-tier pricing and intelligent catalog search without long manual query delays.
- **Technical Architecture**: React.js frontend connected to an Express REST gateway with an in-memory FAISS semantic index and Google Gemini API model.
- **University Evaluation Highlights**: Top marks for real-world commercial viability and sub-300ms vector search response times.
- **Live Portfolio Link**: [moizahmed.online/#work-stitchsmart](https://www.moizahmed.online/#work-stitchsmart)

## 4. Case Study: CCPD Enterprise Management Portal
- **FYP Title**: Institutional Enterprise Portal with Bitwise Role-Based Access Control
